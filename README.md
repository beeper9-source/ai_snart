# 2026 AI 커뮤니티 활동지원 - 모임 결과 보고서 시스템

시안(`3모임결과 보고서.png`)의 UI/UX를 1:1 완벽 구현하고, **최종 선정된 10개 커뮤니티**와 **모임별 최소 3회 의무 진행 요건**을 반영한 모임 결과 보고서 웹 애플리케이션입니다.  
**모든 데이터는 Supabase 클라우드 데이터베이스와 실시간으로 연동**되어 관리됩니다.

---

## 1. 주요 특징 및 구현 내용

1. **표준 커뮤니티 UI/UX 레이아웃**:
   - **좌측 사이드바**: 10개 커뮤니티 분과 채널 (고유 번호, 테마별 아이콘, 프로젝트 한 줄 요약, 모임별 최소 3회 의무 진행도 `● ● ○` 표시)
   - **우측 상단**: 선택된 커뮤니티 대표 정보 및 최소 3회 모임 필수 이행 진행도 배너 (1, 2, 3회차 스테퍼)
   - **우측 기본 화면 (게시글 피드)**: 선택된 커뮤니티의 모임 결과 보고서 목록 피드, 회차 필터(전체/1회차/2회차/3회차/4회차+), 첨부 사진 갤러리(라이트박스 모달 확대), 보고서별 `[ ✏️ 수정 ]` 및 `[ 🗑️ 삭제 ]` 지원
   - **작성/수정 전용 뷰**: `[ ✍️ 새 보고서 작성 ]` 또는 게시글 `[ ✏️ 수정 ]` 클릭 시 전환, `[ ← 보고서 목록으로 돌아가기 ]` 제공
2. **모임별 최소 3번 의무 모임 요건 시각화**:
   - 각 커뮤니티 채널 카드에 `● ● ○ (2/3회 진행)` 등 3단계 진행 점(Dot) 및 달성 상태 표시
   - 상단 안내 배너: 커뮤니티별 모임 진행 현황 및 1회차 ➔ 2회차 ➔ 3회차(필수완료) 실시간 인터랙티브 스테퍼
   - 폼 입력 항목에 `[ 1회차(필수) ]`, `[ 2회차(필수) ]`, `[ 3회차(의무달성) ]`, `[ 4회차+(자율) ]` 선택 지원
3. **Supabase 클라우드 데이터베이스 & Storage 완벽 연동**:
   - `ai_communities`: 10개 선정 커뮤니티 메타 정보 저장 및 조회
   - `ai_community_reports`: 작성된 모임 결과 보고서 저장(게시), 실시간 목록 조회, 수정(Update), 삭제(Delete)
   - `ai_community_drafts`: 커뮤니티별 작성 중인 임시저장 내용 클라우드 보관 및 자동 복원
   - `storage.buckets ('ai-community-photos')`: 첨부 사진 클라우드 Storage 자동 업로드 및 영구 보존
4. **사용자 편의 기능**:
   - `[ ✨ 예시 데이터 채우기 ]`: 클릭 한 번으로 선택된 커뮤니티의 실제 프로젝트에 맞춘 고품질 예시 본문 및 사진 자동 입력
   - `[ 👁️ 미리보기 ]`: 실제 결과물 뷰 모달 창에서 사진 갤러리 및 상세 내용 사전 확인
   - `[ 📄 모임 결과 보고서 PDF 다운로드 ]`: 공식 서식 제2호 양식(성남미디어센터 공식 로고, 기본 정보 테이블, 모임 활동 본문, 현장 사진 갤러리, 공식 제출 서명부)으로 A4 규격 PDF 자동 생성 및 즉시 다운로드
   - `[ 📋 보고서 보관함 ]`: 전체 제출된 보고서 모아보기 및 수정/삭제/PDF 다운로드
   - `[ 🟢 Supabase 실시간 연동됨 ]`: 헤더 상단 뱃지 클릭 시 즉시 클라우드 최신 데이터 동기화
   - **GitHub Pages 실시간 배포**: [https://beeper9-source.github.io/ai_snart/](https://beeper9-source.github.io/ai_snart/)

## 3. Supabase 데이터베이스 스키마

- **프로젝트 URL**: `https://dmgtwzbvpualecnrcyug.supabase.co`
- **테이블 구조**:
  1. `public.ai_communities`: 커뮤니티 번호, 명칭, 단체구분, 대표자, 프로젝트명, 최소필수의무(3회)
  2. `public.ai_community_reports`: 보고서 UUID, 커뮤니티ID, 회차(1~3), 제목, 일시, 장소, 참석자(JSONB), 본문(HTML), 키워드(JSONB), 사진(JSONB)
  3. `public.ai_community_drafts`: 커뮤니티별 작성 중 임시저장 데이터
  4. `public.ai_community_comments`: 보고서 댓글 (UUID, 보고서ID 외래키 ON DELETE CASCADE, 작성자명, 댓글 본문, 작성일시)
  5. `storage.buckets ('ai-community-photos')`: 첨부 사진 클라우드 스토리지

```bash
# Python으로 로컬 서버 실행 예시 (권장)
python -m http.server 8080
# 브라우저 접속: http://localhost:8080
```
